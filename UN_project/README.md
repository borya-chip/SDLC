# Лабораторная работа 1

Дисциплина: «Жизненный цикл разработки программного обеспечения».

Вариант 20: программа «Возраст в неожиданных единицах».

Язык: Java 17.

## Функциональность

- Главное окно содержит кнопку `Ввести данные`.
- Дата рождения вводится в отдельном окне через три обычных текстовых поля: день, месяц, год.
- Стандартный элемент выбора даты не используется.
- Последняя корректно введенная дата хранится в главном окне и подставляется при повторном вводе.
- Допустимая дата рождения начинается с `01.01.1926` и не может быть позже текущей даты.
- Проверяются реальные календарные даты, включая длину месяцев и високосные годы.
- При некорректных данных показывается стилизованное окно ошибки с введенной датой и кнопкой `OK`.
- После расчета отображаются возраст в годах, месяцах, днях, минутах, чашках кофе, сериях сериала и километрах ленты соцсетей. Для расчета используются усреднения: 2 чашки кофе и 300 метров ленты соцсетей в день.
- Использован каркас MVC с активной моделью: `AgeModel` после пересчета вызывает событие `StateChanged`, а главное окно обновляет отображение.

## Структура

- `src/main/java/ageunexpectedunits/models/AgeModel.java` - активная модель и расчет результатов.
- `src/main/java/ageunexpectedunits/models/AgeCalculationResult.java` - объект результата.
- `src/main/java/ageunexpectedunits/controllers/AgeController.java` - контроллер, валидация ввода и передача данных модели.
- `src/main/java/ageunexpectedunits/views/MainForm.java` - главное окно на Swing.
- `src/main/java/ageunexpectedunits/views/InputForm.java` - окно ввода даты рождения.
- `docs/mvc.puml` - UML-схема MVC-каркаса.
- `.vscode/extensions.json` - рекомендованные расширения для Java, UML и SysMLv2.

## Запуск

С установленным JDK 17 или новее:

```bash
javac --release 17 -d out $(find src/main/java -name '*.java')
java -cp out ageunexpectedunits.Program
```

При наличии Maven:

```bash
mvn compile exec:java
```

Для создания исполняемого JAR-файла:

```bash
mvn package
java -jar target/age-unexpected-units.jar
```
