# Проект по дисциплине «Жизненный цикл разработки ПО»

* **Автор:** Кулешов Станислав Сергеевич
* **Группа:** 450503
* **Дисциплина:** Жизненный цикл разработки программного обеспечения

## Описание проекта
Разработать программу «Возраст в неожиданных единицах». Пользователь вводит дату рождения (без стандартного поля даты), а программа считает его возраст в годах, месяцах, днях, минутах, чашках кофе, сериях сериала и прокрученных километрах ленты соцсетей.

### Основной функционал:
1. **Главная форма:**
    * Кнопка «Ввести данные» для вызова дополнительного окна ввода.
    * Отображение результата: возраст в годах, месяцах, днях, минутах, чашках кофе, сериях сериала и километрах прокрученной ленты соцсетей.
    * Запоминание последних введённых данных в главном окне и их восстановление при повторном вводе.

2. **Диалоговое окно ввода:**
    * Ввод даты рождения (без использования стандартного встроенного элемента ввода даты).

3. **Обработка ошибок:**
    * Показ сообщения об ошибке при вводе некорректных данных.
